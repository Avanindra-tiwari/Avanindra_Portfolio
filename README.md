# Avanindra Tiwari — Animated Portfolio

Premium responsive React portfolio using Vite, Framer Motion and Lucide.

## Run
```bash
npm install
npm run dev
```

## Before publishing
Open `src/main.jsx` and edit the clearly marked `personal` object:
- `college`
- `email`
- `phone`
- `location`
- `github`
- `linkedin`
- `resume`

Also edit the `education` object for your year.

Project descriptions/tags are in the `projects` array. Add your real GitHub/demo URLs there if desired.

For a resume button, put your PDF at `public/resume.pdf`.
